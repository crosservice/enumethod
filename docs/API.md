# Enumethod API Reference

Base URL: `/api`

All endpoints except auth require a Bearer token in the Authorization header.

## Auth

### POST /auth/login
Rate limited: 5 requests/minute.

**Body:**
```json
{ "username": "admin", "password": "TestifyThusly99@" }
```

**Response:**
```json
{ "accessToken": "eyJ...", "refreshToken": "eyJ..." }
```

### POST /auth/refresh
**Body:**
```json
{ "refreshToken": "eyJ..." }
```

**Response:** Same as login.

### POST /auth/logout
Requires auth. Invalidates refresh token.

## Users (admin only)

### GET /users
List all users.

### POST /users
```json
{ "username": "viewer", "password": "SecurePass1!", "role": "view" }
```

### PATCH /users/:id
```json
{ "role": "admin", "password": "NewPass123!" }
```
Both fields optional.

### DELETE /users/:id
Delete a user.

### POST /users/change-password
Self-service, any authenticated user.
```json
{
  "currentPassword": "old",
  "newPassword": "new12345",
  "confirmPassword": "new12345"
}
```

## Runs

### GET /runs?page=1&limit=20
Paginated list of all runs.

### GET /runs/:id
Run detail.

### GET /runs/:id/outputs
Per-command output records for a run.

### POST /runs (admin only)
Start a new enumeration.
```json
{
  "targetIp": "192.168.1.100",
  "domain": "example.com",
  "steps": "1,2,3",
  "timing": 4,
  "wordlist": "/usr/share/seclists/...",
  "skipUdp": false,
  "skipBruteforce": false,
  "dryRun": false
}
```
Only `targetIp` is required.

### POST /runs/:id/pause (admin only)
Pause a running scan.

### POST /runs/:id/resume (admin only)
Resume a paused scan.

### POST /runs/:id/cancel (admin only)
Kill a running/paused scan.

---

## Reports

### GET /runs/:id/report

### GET /runs/:id/export

## WebSocket

Connect to `/ws/runs` namespace with Socket.IO.

Auth via handshake: `{ auth: { token: "eyJ..." } }`

Emit `subscribe` with `{ runId }` to join a run's room.

Events received: `catchup`, `output`, `status`.
